# Machine Learning Projects

This repository contains a collection of machine learning projects covering applications in healthcare, hardware security, and predictive maintenance.  
Each project demonstrates different aspects of the ML pipeline including data preprocessing, feature engineering, model development, and performance optimization.

---

## Projects Included

### 1. Hardware Trojan Detection using Lightweight Ensemble Learning
A machine learning framework for detecting hardware Trojans in gate-level VLSI circuits using structural and statistical features.

**Highlights**
- Hybrid feature selection using ANOVA F-score, Mutual Information, and Random Forest importance
- Lightweight ensemble model combining KNN, Random Forest, and LightGBM
- Achieved **99.50% accuracy on CAS-Lab** dataset
- Achieved **99.80% accuracy on HT-PRED** dataset

**Technologies**
Python, Scikit-learn, LightGBM, Random Forest, KNN, Pandas, NumPy

### 2. Heart Disease Prediction using ECG Signal Processing
A machine learning pipeline for detecting myocardial infarction using ECG signals from the PTB Diagnostic ECG dataset.

**Highlights**
- ECG signal preprocessing and feature extraction
- Extraction of physiological features such as RR interval and QRS duration
- SVM classifier achieving **83% accuracy**
- 1D CNN model improving performance to **~85% accuracy**

**Technologies**
Python, Scikit-learn, TensorFlow, NumPy, SciPy, Pandas, WFDB

### 3. AI-Powered Predictive Maintenance for Aircraft Engines
A predictive maintenance model to estimate Remaining Useful Life (RUL) of aircraft engines using sensor data.

**Highlights**
- Built a machine learning pipeline using XGBoost
- Applied feature scaling and preprocessing for sensor data
- Optimized model execution using **Intel AI libraries and parallel computing**
- Reduced training time from **5.31s to 2.65s**

**Technologies**
Python, XGBoost, Intel Scikit-learn Extension, Modin, Ray, SHAP, Pandas, NumPy
